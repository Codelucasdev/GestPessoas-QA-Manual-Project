## TC02: Apagar First Name ou Last Name

Quando o administrador clica em First Name ou Last Name

E apaga o First Name ou Last Name

E clica no botão Save

![Relatório 06, captura 3](../evidencias/06/captura-03.png)

**Resultado esperado:** Então a mensagem “Required” é exibida logo abaixo do First Name ou Last Name e a alteração não é salva

**Resultado obtido:** Então a aplicação impede que a alteração seja feita e exibe a mensagem ”Required” logo abaixo do campo apagado.
